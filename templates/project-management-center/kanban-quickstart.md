# Kanban 看板快速开始

## 打开

直接用浏览器打开同目录的 `kanban.html` 即可，无需安装依赖、启动服务或联网。支持现代桌面和移动浏览器。

## 使用流程

1. 点击「新建任务」，填写执行人、收件人、交付位置、验收标准、交付时间和下次检查时间。任务先登记，默认进入「待接单」。
2. 执行人确认接单后，点「确认接单」进入「执行中」。这不代表成果已交付。
3. 到约定时间人工检查。需要回收成果时进入「待回收」；实际确认交付物存在后，点「收到成果」或「补交成果」，登记位置与版本。
4. 在「待核验」卡片点「核验 / 决定」，逐条选择通过或未通过并填写证据。全部通过且证据齐全后，可由收件人确认验收；有未通过项时写明退回原因，任务回到「退回待补」。
5. 取消任务须填写原因并二次确认，且仅由有权限的负责人操作。
6. 定期用「导出 JSON」备份。导入会替换当前看板数据；不要把 JSON 文件发给未经授权的人。

## 状态

`待接单 → 执行中 → 待回收 → 待核验 → 已验收`

核验未通过时：`待核验 → 退回待补 → 待核验`

只有「已验收」和有原因的「已取消」会进入已关闭任务区。其余任务都留在活动看板。

## 数据与边界

- 数据保存在当前浏览器的 localStorage，不会自动上传、同步或备份。清除浏览器站点数据可能丢失记录。
- 这是单人本地看板，不包含账号、多人协作、云端存储、自动提醒、定时检查或自动派工。
- 每次状态推进都由使用者明确点击；到点检查、成果真实性判断及最终验收由人负责。
- 不要在看板中保存密码、API 密钥、支付信息或不必要的敏感个人数据。
- 该文件是可直接运行的单页原型；若要多人线上使用，需要另行建设身份验证、服务端存储、权限控制、审计和备份。
